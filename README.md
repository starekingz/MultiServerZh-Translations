# MultiServerZh Translations

OPLegends 英翻繁體中文詞庫，共 2828 條。依主要顯示位置分為三份；同一段文字可能在不同畫面共用。

| 檔案 | 用途 | 條數 |
| --- | --- | ---: |
| [oplegends.chat.zh-TW.json](packs/oplegends.chat.zh-TW.json) | 聊天訊息、系統公告、NPC 對話 | 928 |
| [oplegends.items.zh-TW.json](packs/oplegends.items.zh-TW.json) | 物品名稱、Lore、附魔、介面物品 | 1634 |
| [oplegends.other.zh-TW.json](packs/oplegends.other.zh-TW.json) | 記分板、Action Bar、Boss Bar、浮空文字、標題 | 266 |

## 手動匯入

MultiServerZh 0.5.16 起，連線到目標伺服器後執行：

```text
/mszh import oplegends
```

一次下載三份分類詞庫，全部驗證成功後才合併至本地；任一下載失敗都不更新。只有執行指令或點擊更新按鈕才套用更新；進服會依 IP 檢查對應翻譯包。保留本地人工修改，匯入前備份。下載後可離線使用。

[packs/oplegends.zh-TW.json](packs/oplegends.zh-TW.json) 保留為舊版相容合併檔；維護時請修改三份分類檔，並同步產生合併檔。新模組預設從分類檔讀取，分類僅方便維護，匯入後仍可跨顯示位置共用。

## 物品翻譯

完整匹配保留整卡譯文，行與行不再繼承標題粗體。整卡未匹配時優先使用已有逐行規則，無法拆開的描述再嘗試段落翻譯。從詞庫中衍生無歧義的名稱、描述與欄位規則；數值使用佔位符，支援等級、機率等變動。已滿級、鎖定、啟用及停用狀態可獨立匹配。缺少的英文仍保留供後續收集，不猜測新附魔效果。

## 0.5.17 浮空文字

支援多行 Text Display 與拆成多個盔甲座的逐行顯示，從既有譯文衍生無歧義的單行規則。匹配時忽略前後空白、特殊空格與零寬字元；未匹配內容仍收集到 missing，已知單行不再誤報缺詞。保留原始實體資料，只替換渲染文字。

## 維護

- JSON 鍵為英文來源，值為繁體中文；換行使用 `\n`。
- 來源與譯文的 `{0}` 等佔位符集合必須一致，不能漏掉數字、網址或指令。
- 分類之間不能有相同來源卻不同譯文；新模組會拒絕匯入衝突。
- 不存放玩家私人聊天、missing 清單或機翻快取。
- F9 開啟設定；F8 擷取物品完整原文與格式，右鍵功能在設定切換。

遊戲內動畫、字型與其他模組的相容性仍需實測。

## 0.5.22 浮空文字誤匹配修正

## 0.5.31 伺服器位址標記

[packs/oplegends.servers.json](packs/oplegends.servers.json) 標記此詞庫適用位址為 `play.oplegends.com`。進入多人伺服器後，先將目前連線地址與遠端 `server_ips` 比對，匹配才下載分類檔檢查更新；不匹配則不顯示更新提示。點擊更新／手動匯入亦重新檢查，避免匯入到其他伺服器。

位址比對忽略大小寫、結尾的點與預設連接埠 `25565`，不使用伺服器清單名稱、DNS解析或子網域猜測；其他連接埠必須另外標記。預設詞庫的位址標記與分類檔固定使用同一commit。自訂單檔URL須提供同目錄、同檔名前綴的 `.servers.json`（例如 `custom.json` 對應 `custom.servers.json`），格式同上述檔案。

## 0.5.32 伺服器翻譯包隔離

進服時讀取 [packs/index.json](packs/index.json)，依索引逐一檢查 `<pack>.servers.json` 的 `server_ips`，顯示對應的 `server_name`，不使用玩家伺服器清單名稱。OPLegends 對應 `play.oplegends.com`。索引、位址標記與三份分類詞庫固定在同一 Git commit；重複 IP 標記會拒絕匯入，避免誤選翻譯包。

本地詞庫依正規化連線位址分開儲存與載入；進出伺服器會清除畫面快取。沒有該伺服器的本地詞庫時保持原文，仍可蒐集 missing；遠端有對應包時顯示可點擊更新，遠端也沒有時提示無翻譯包。遠端查詢失敗會明確提示，已有的本地譯文仍可離線使用。`/mszh import` 自動尋找當前伺服器翻譯包，舊指令 `/mszh import oplegends` 保留相容。

新增伺服器時，在索引的 `packs` 加入唯一識別字（小寫英數、底線或連字號），並提供同名前綴的 `.servers.json`、`.chat.zh-TW.json`、`.items.zh-TW.json`、`.other.zh-TW.json`。名稱取自標記檔，三類內容全部驗證成功後才匯入。自訂單檔 URL 沿用同名前綴 `.servers.json` 的方式。
