# MultiServerZh Translations

OPLegends 英翻繁體中文詞庫，共 1663 條。依主要顯示位置分為三份；同一段文字可能在不同畫面共用。

| 檔案 | 用途 | 條數 |
| --- | --- | ---: |
| [oplegends.chat.zh-TW.json](packs/oplegends.chat.zh-TW.json) | 聊天訊息、系統公告、NPC 對話 | 208 |
| [oplegends.items.zh-TW.json](packs/oplegends.items.zh-TW.json) | 物品名稱、Lore、附魔、介面物品 | 1262 |
| [oplegends.other.zh-TW.json](packs/oplegends.other.zh-TW.json) | 記分板、Action Bar、Boss Bar、浮空文字 | 193 |

## 手動匯入

MultiServerZh 0.5.16 起，連線到目標伺服器後執行：

```text
/mszh import oplegends
```

一次下載三份分類詞庫，全部驗證成功後才合併至本地；任一下載失敗都不更新。只有執行指令或點擊匯入按鈕才更新，登入與啟動不會自動下載。保留本地人工修改，匯入前備份。下載後可離線使用。

[packs/oplegends.zh-TW.json](packs/oplegends.zh-TW.json) 保留為舊版相容合併檔；維護時請修改三份分類檔，並同步產生合併檔。新模組預設從分類檔讀取，分類僅方便維護，匯入後仍可跨顯示位置共用。

## 物品翻譯

完整匹配保留整卡譯文，行與行不再繼承標題粗體。整卡未匹配時優先使用已有逐行規則，無法拆開的描述再嘗試段落翻譯。從詞庫中衍生無歧義的名稱、描述與欄位規則；數值使用佔位符，支援等級、機率等變動。已滿級、鎖定、啟用及停用狀態可獨立匹配。缺少的英文仍保留供後續收集，不猜測新附魔效果。

## 0.5.17 浮空文字

支援多行 Text Display 與拆成多個盔甲座的逐行顯示，從既有譯文衍生無歧義的單行規則。匹配時忽略前後空白、特殊空格與零寬字元；未匹配內容仍收集到 missing，已知單行不再誤報缺詞。保留原始實體資料，只替換渲染文字。

## 維護

- JSON 鍵為英文來源，值為繁體中文；換行使用 `\n`。
- 來源與譯文的 `{0}` 等佔位符集合必須一致，不能漏掉數字、網址或指令。
- 分類之間不能有相同來源卻不同譯文；新模組會拒絕匯入衝突。
- 不存放玩家私人聊天、missing 清單或機翻快取。
- F9 開啟設定；F8 擷取物品完整原文與格式，右鍵功能在設定切換。

遊戲內動畫、字型與其他模組的相容性仍需實測。

## 0.5.22 浮空文字誤匹配修正

移除從名單列衍生的純佔位符／標點規則，例如 `{0} ({1}) → {0}（{1}）`。此規則會把未翻譯的英文指引誤當作已知文字，只改括號。衍生規則現在必須包含固定單詞；缺詞會正常收集。新增 `Walk into the Portal` 與帶距離版本的譯文，並保留距離整段的灰色、單位與非粗體樣式。一般漸層文字不會因此被阻擋翻譯。

更新模組至 0.5.22，並執行 `/mszh import oplegends` 手動更新詞庫。
